⚡ Optimización

Estrategias de Reranking y Reducción de Costos

Cómo triplicar la precisión y reducir en 60% la ventana de tokens inyectada al LLM.

1. Two-Stage Retrieval

Recuperar 50 candidatos rápidos con BM25/Vector → Reducir a los Top-5 más relevantes con Cohere Rerank 3.

2. Contextual Chunking

Pre-inyectar el resumen del documento al inicio de cada fragmento antes de vectorizar para evitar pérdida de contexto.

3. Prefix Caching

Aprovechar el Prompt Caching de Claude / Gemini para ahorrar 90% en tokens de contexto repetidos.

📋 Checklist de Producción

Checklist RAG Enterprise para GeekSoft

Criterios de aceptación antes de desplegar un pipeline RAG en producción.

1. Chunking Validado

Chunk size adaptado a la densidad del documento (500-1000 tokens con 15% overlap).

2. Reranker Activo

Filtro de relevancia semántica antes de llamar al modelo generador.

3. Citas Estrictas

El LLM debe devolver metadatos con número de página y chunk fuente verificado.

4. Latencia < 1s

Streaming SSE activo para visualización instantánea del primer token.
