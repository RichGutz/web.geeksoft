🏛️ ↔ 🛋️ Los Dos Gemelos

Arquitectura Dual: PROPTWIN (Macro) vs ARBN.CPJS (Micro)

Dos proyectos complementarios construidos en paralelo sobre la misma fábrica agéntica.

🏛️ PROPTWIN: El Gemelo Macro-Patrimonial

• Escala: Cartera corporativa de ~400 predios del Arzobispado de Lima.
• Enfoque: Georreferenciación PostGIS, saneamiento Sunarp, títulos registrales y arbitrios SAT.
• Actor Clave: Cancillería, Directores de Inmuebles, Abogados Litigantes.
• Métrica Clave: Saneamiento de cartera, rentas patrimoniales y reducción de litigios.

🛋️ ARBN.CPJS: El Gemelo Micro-Remodelación

• Escala: Unidades individuales (60 m² a 150 m²) para Airbnb / Alquiler.
• Enfoque: Virtual Staging ControlNet, despiece BOQ de partidas, equipamiento y menaje.
• Actor Clave: Anny Rojas, Propietarios e Inversionistas de Remodelación.
• Métrica Clave: Retorno de inversión (ROI), costo por $m^2$ y calificación 5 estrellas.

🛠️ Stack Tecnológico

Stack de Producción: React TypeScript, Python & Supabase Storage

Arquitectura full-stack desacoplada con el sistema de diseño visual APEFAC Enterprise Light.

🎨 Frontend: React 19 + TypeScript + APEFAC

• Vite + TypeScript: Compilación estricta y velocidad instantánea.
• UI APEFAC Light: `#F8FAFC`, Navy `#0F172A`, Sky `#0284C7`, Emerald `#059669`.
• Staging Slider: Comparador Before/After fotorrealista por ambiente.
• BOQ Table: TanStack Table con toggles de aprobación en vivo.

🐍 Backend: Python 3.12 + FastAPI

• FastAPI Async: Contratos OpenAPI 3.1 tipados con Pydantic v2.
• Parser Informal: Extracción NLP de cotizaciones de WhatsApp/PDF.
• SBS Scraper: Tipo de cambio diario oficial USD/PEN.
• OpenTakeoff: Metrados de planos PDF (áreas y perímetros).

🗄️ Database: Supabase Cloud

• PostgreSQL 16: Tablas `proyectos`, `partidas_boq`, `items_airbnb`.
• Supabase Storage S3: Buckets para fotos originales, planos y renders IA.
• Row Level Security (RLS): Acceso seguro para clientes y equipo de obra.
• Auth & 2FA: Inicio de sesión protegido.

💻 Entorno de Ejecución

¿Dónde Trabajan los Agentes? Distribución PC Local vs Contabo VPS

Tu PC local se mantiene 100% liviana y fría; la carga pesada de inferencia y pruebas vive en el VPS Contabo.

💻 Tu PC Local (Cabina de Control)

• Carga: < 5% CPU / Cero ruido térmico.
• Editor: Antigravity IDE (prompts, Spec Kits y Git).
• Preview: Vite dev server liviano para ver la UI.
• Rol: Human-in-the-Loop para toma de decisiones clave.

🚀 Contabo VPS (169.58.168.107) - Fábrica Pesada

• Docker Sandboxes: Agentes compilan y prueban en contenedores.
• QC Automated: `pytest`, `mypy` y `tsc --noEmit` en background.
• Worker Staging IA: Inferencia de ControlNet y procesamiento de imágenes.
• Multi-Agent: LangGraph ejecutando bucles autónomos.

☁️ Supabase Cloud (Datos & Renders)

• Persistencia Relacional: Partidas, cotizaciones y presupuestos.
• Storage S3: Fotos en alta resolución y renders generados.
• Cero Mantenimiento: Sin instalar bases de datos en tu laptop.

🎨 Staging Visual IA

Virtual Staging con Preservación Estructural (ControlNet)

Transformación fotorrealista sin deformar las dimensiones reales del departamento.

1. Limpieza de Escena (Declutter)

• El modelo `ai-room-declutter` remueve muebles rotos, ropa o desorden.
• Genera un lienzo limpio del espacio respetando la perspectiva original.

2. Bloqueo Estructural (ControlNet)

• Detección de aristas y segmentación (`controlnet-seg-room`).
• Mantiene inalterables: vigas, columnas, ventanas, puertas y tomas eléctricas.

3. Render de Estilo Personalizado

• Aplicación de prompts calibrados para estilo Japandi, Nórdico o Industrial.
• Muestra al cliente el acabado final exacto con iluminación realista.
