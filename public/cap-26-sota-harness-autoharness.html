💻 INTEGRACIÓN EN ANTIGRAVITY & CLAUDE CODE

Modos de Integración: Daemon Autónomo vs Slash Command /learn

Dos modalidades operativas para transformar el IDE en un sistema auto-evolutivo.

Opción A: Daemon Hooks en Sesión

Monitorea el flujo de mensajes y comandos. Tras N pasos con éxito continuo o corrección de bugs, compila el workflow en `.agents/skills//SKILL.md` sin intervención del operador.

Opción B: Slash Command Explícito (/learn)

El operador ejecuta `/learn` al resolver una tarea compleja. El asistente extrae el RCA, los comandos deterministas y actualiza la bóveda temática de inmediato.

# Ejemplo de Skill Autogenerado por autoharness --- name: petral-traefik-deploy description: "Protocolo inmutable de inyección dinámica Traefik con DNS Pre-Flight Check" --- # Rules: 1. Validar Resolve-DnsName antes de tocar dynamic YAML. 2. Inyectar /data/coolify/proxy/dynamic/petral.yaml con priority 5000. 3. Certificar latencia < 10ms en /health.
