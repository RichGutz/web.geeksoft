Fine-Tuning Tradicional vs Reinforcement Learning Agéntico

Por qué el entrenamiento por recompensa supera al aprendizaje supervisado (SFT) en tareas de programación.

Dimensión Supervised Fine-Tuning (SFT) Agent Lightning (RL Proxy)
Dificultad de Datos Requiere miles de ejemplos curados a mano Solo requiere una función de recompensa (Tests)
Manejo de Errores Aprende a imitar, no a auto-corregirse Explora caminos y aprende a recuperarse de fallas
Costo de Dataset Extremadamente costoso ($$$) Generación autónoma en sandboxes locales
Adaptación a Reglas Baja retención de constraints estrictos Penalización directa si viola normas de código

💻 FUNCIÓN DE RECOMPENSA EN PRODUCCIÓN

Diseño de la Función de Recompensa R(s, a)

Implementación de recompensas densas y dispersas para guiar al agente hacia soluciones limpias y minimalistas.

def compute_agent_reward(trajectory, execution_result) -> float: reward = 0.0 if execution_result.exit_code == 0: reward += 1.0 # Éxito en terminal else: return -1.0 # Falla determinista inmediata # Bonificación por concisión y reducción de código (Ponytail AI #107) if trajectory.lines_changed < trajectory.baseline_lines: reward += 0.5 # Recompensa por anti-bloat # Penalización por llamadas redundantes a herramientas reward -= 0.05 * len(trajectory.tool_calls) return max(reward, -1.0)
