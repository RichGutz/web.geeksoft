❌ EL PROBLEMA DEL DRIFT VISUAL

Por qué los Agentes Destruyen el Diseño Tradicional

Análisis de la causa raíz de las interfaces "Frankenstein" generadas por IA.

❌ Diseño No Preparado para IA (Drift Extremo)

• El modelo inventa botones, bordes y sombras en cada prompt.
• Introduce 10 tonos diferentes de azul sin consistencia.
• Escribe estilos inline (`style="margin-top: 17px;"`) imposibles de mantener.
• Ruptura de la accesibilidad y el modo oscuro.

✅ AI-Ready Design System (GeekSoft Standard)

• Catálogo cerrado de componentes modulares (`src/components/`).
• Gramática estricta de espaciado y tipografía (Escala 4px/8px).
• Regla de oro: Si un componente no está en el Spec File, está prohibido crearlo.
• Consistencia visual del 100% en todas las pantallas.

Atlassian Research: Los Spec Files reducen el retrabajo de UI en un 82%Slide 2 / 6
📝 ANATOMÍA DE UN SPEC FILE

Estructura del Contrato de Diseño: DESIGN_SPEC.md

El archivo que todo asistente de IA debe leer antes de escribir una sola línea de frontend.

# GEEKSOFT DESIGN SYSTEM SPEC (AI-READY V1.0) ## 1. Color Palette Tokens: - Background Master: var(--bg) [#F8FAFC] | Cards: var(--bg-card) [#FFFFFF] - Brand Accent: var(--sky) [#0284C7] | Success: var(--emerald) [#059669] - Neutral Text: var(--navy) [#0F172A] | Muted: var(--text-dim) [rgba(15,23,42,0.68)] ## 2. Typography Rules: - Display/Headings: 'Outfit', sans-serif (Font-weight: 800-900) - Body/UI: 'Inter', -apple-system (Font-weight: 400-600) - Code/Data: 'JetBrains Mono', monospace (Font-weight: 700) ## 3. Strict Prohibitions: - Prohibido el uso de colores HEX directos en componentes. - Prohibidos los monolitos HTML: Todo componente debe ser modular en src/components/.

🧩 ARQUITECTURA MODULAR APEFAC

El Estándar Modular: React 19 + Tailwind CSS

Estructura de directorios desacoplada para evitar el colapso de archivos gigantes.

📂 src/components/

Componentes puros y atómicos: `Button.jsx`, `MetricCard.jsx`, `TableGrid.jsx`, `Modal.jsx`.

📊 src/data/

Contratos de datos tipados y mock datasets para pruebas en aislamiento sin backend vivo.

⚡ src/lib/

Motores de cálculo deterministas, formateadores de moneda y clientes API HTTP.
