🔄 PIPELINE DE 3 PASOS

Por qué Desacoplar Geometría, Estilo y Animación

El error común es pedirle a un LLM que genere una animación compleja en un solo prompt.

❌ Prompt Único Monolítico

• El modelo colapsa calculando coordenadas y animaciones al mismo tiempo.
• SVG roto con viewBox inconsistente y paths cortados.
• Animaciones espasmódicas que no respetan los 60 FPS.

✅ Pipeline de 3 Pasos (Claude Workflow)

• Paso 1 asegura topología y viewBox perfecto (1920x1080 o 800x600).
• Paso 2 aplica la paleta oficial (Navy, Sky, Emerald).
• Paso 3 inyecta transformaciones CSSGPU-accelerated (`transform: translate3d`).

Resultado: Animaciones fluidas a 60 FPS sin saltos ni parpadeosSlide 2 / 6

💻 EJEMPLO DE CÓDIGO DETERMINISTA

Generación de SVG Morphing con CSS Puro

Implementación ligera sin librerías externas pesadas.

@keyframes pulseGlow { 0%, 100% { transform: scale(1); filter: drop-shadow(0 0 8px rgba(2,132,199,0.4)); } 50% { transform: scale(1.05); filter: drop-shadow(0 0 20px rgba(2,132,199,0.8)); } } .agent-node { transform-origin: center; animation: pulseGlow 3s infinite ease-in-out; will-change: transform, filter; }
