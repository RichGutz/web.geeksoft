⚠️ LA PATOLOGÍA DEL AI SLOP

Cómo la IA Destruye Codebases sin Control Riguroso

Los tres síntomas mortales del código generado por asistentes descuidados.

1. Borrado Accidental

El modelo reescribe un archivo y "olvida" botones de esquinas, widgets de zoom o menús funcionales.

2. Inflación de Dependencias

Instala paquetes npm/pip de 50MB para resolver funciones que se hacen en 3 líneas de código nativo.

3. Hallucinated APIs

Usa métodos y argumentos inventados que no existen en las versiones actuales de las librerías.

🔪 LAS REGLAS DE CIRUGÍA DE KARPATHY (K0)

El Decálogo del Cirujano de Código (Nota #146)

Principios inmutables para intervenir proyectos de producción sin causar regresiones.

Principio de Cirugía Regla Operativa Verificación Obligatoria
1. Diff Check Obligatorio Revisar cada línea añadida/eliminada contra el baseline. `git diff --stat` & inspección de chunks
2. Preservación Funcional Prohibido tocar componentes fuera del alcance de la tarea. Verificación visual en navegador / sandbox
3. Backups Inmutables Crear versiones `_V1, _V2` o branches antes de intervenciones mayores. Git Branch Tags con fecha
4. Terminal Verification Todo cambio debe ser ejecutado y probado en terminal. Salida explícita con Exit Code 0

📉 EL ENFOQUE PONYTAIL (P0): STDLIB-FIRST

Reducción Sistemática de Código ≥ 50%

Menos código significa menos bugs, menor superficie de ataque y menor costo de contexto.

Eliminación de Middleware Fantasma

Reemplazar frameworks inflados por scripts puros de Python (urllib, json, sqlite3) y módulos nativos de Node.js.

Consolidación de Helpers Redundantes

Fusionar 10 archivos de utilidades dispersas en un único módulo compacto y fuertemente tipado.
